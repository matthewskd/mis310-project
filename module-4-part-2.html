Module 4 - Part 2

Your site has structure, content, and CSS. Now we are going to work on how those pieces are arranged on the page and what happens when the amount of available space changes.

Module 4 introduces Flexbox, a CSS layout system designed to arrange elements in rows or columns and control the space between them. You will use Flexbox to move beyond the browser's normal page flow and begin building intentional layouts.

Then we will add responsive design. A responsive site does not assume that every visitor has the same screen. Your layout should be able to adapt when someone views it on a large desktop monitor, a laptop, a tablet, or a phone.

The goal is not to create separate desktop and mobile versions of your site. The goal is to build one site that responds to the space available to it.
