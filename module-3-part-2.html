Module 3 - Part 2

Your site has structure, images, links, and multimedia. Now you get to decide how it looks.

Module 3 introduces Cascading Style Sheets (CSS), the language browsers use to control presentation. Across these two weeks, you will learn how selectors connect CSS rules to HTML, how properties control typography and color, and how the box model controls the space around every element on a page.

The goal is not to make your site look finished. We still have Flexbox, responsive design, and CSS Grid ahead of us. Flexbox and CSS Grid give you more powerful layout tools, while a responsive design will help your site adapt to different screen sizes. The goal is to begin making intentional visual decisions and to understand why your CSS produces the result you see.
